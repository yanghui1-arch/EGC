## 结论与决定

120份响应全部结构通过。60例均可成对比较，420个条件位置中407项状态一致、13项不同，分歧分布于11例。**结构通过和两组一致均不等于正确。** 13处分歧的探索性审阅意见为flat较合理4处、bound较合理4处、范围或定义待裁决5处，不能据此报告准确率、统计显著性或绑定优势。

H3尚无支持。暂选较简单的flat作为后续默认抽取器，bound保留为对照；不继续围绕这些样本付费调提示。这个决定基于复杂度与未见增益，不是认定flat准确率更高。H1/H2仍未进行效果实验，核心创新仍是相同证据下egc对concat的规则组合增量。

更紧迫的问题是输入：至少两例含具体量刑建议，一对案件高度近似，还有说理混入及目标罪名/主体范围疑点。当前池和旧标注均不放行训练；先做一次全候选池离线审计、保留溯源，再处理被确认的问题并准备真实规则。

## 输入审计发现

1. 第23行`7b5ae0e7f890fd8e2b59`含具体月数及罚金量刑建议，第39行`27ae78b6b0dd75720f00`含被遮盖的刑种和以中文数词表示的年数建议。原筛查规则漏掉了间隔文字、遮盖符和中文数字。它们属于预测目标相关信息，当前不能当纯案情输入。
2. 第11、23、31、34、38、39、44、45、46、48、49、54、56、60行至少存在需要复核的公诉/辩护意见、法院采纳说理或量刑定性内容。不是每段都确定泄漏，不能统一删除某个机构名称之后的所有事实。前科刑期也可能是有效事实，不能按刑期关键词直接删除。
3. 第8、10、47、54行有多犯罪范围问题；第11行原标签与公诉描述罪名不同，可能涉及最终定性变化；第19行叙述多个被告人。来源meta已筛为单罪名/单被告，并不能保证facts文本范围唯一；需追溯原始记录，不能自动改罪名或刑期。
4. 第45行`1ac48abd30d37fdb3fe7`与第49行`535bd8ba03b6010abd02`高度近似：原train源行40942 / 38883，标签均为抢劫、144月，字符5-gram包含率0.9932；主要差异是姓名缩写。至少存在这一对，不能把60行视为60个已证实独立案件，也不能推断其他样本没有重复。

这些发现不改变旧E3的样本、分母或报告，不删除问题行后重写历史结果。它们限制该先导的代表性和后续训练可用性。
