审阅结论：

- A/B的明确抓获均识别为主动到案的反证；B的受雇未被推断为明确次要作用。C的证据目录没有再被当作抓获或如实供述事实。D的归案方式保持unknown，家属已履行退赔被识别为supported。E按冻结规范将传唤混合表述保留unknown，并识别明确如实供述。F未再将追缴误作本人退赔或主动到案的反证。上述旧问题在本轮这些开发例中未重现；不能据此推断新样本效果。
- 前七项条件在读取到的两组原始状态中一致；未发现这些已知例中的新增明确误归。谅解、前科、未成年等条件没有正/负例覆盖，不能据大量unknown认定它们已可靠。
- 正式可比较5个案件、40个条件位置，38个相同。仅C/F的全案未得逞不同。这是方案间一致程度，不是正确率；正式统计仍排除E整条flat输出，失败计入总体覆盖率。
- C中bound已抽到结果实现，却因coverage=single_event被门控为unknown。单个事件与覆盖全案并非天然互斥：只有一次相关行为的案件中，单次结果可能恰好代表全案。当前枚举及门控可能造成不必要弃答。F的bound没有抽取结果实现事件，而flat依据已取得财物的叙述给出反证。两例都不能把更多unknown自动称为更准确；C更像范围建模问题，F还涉及事件漏抽。
- 无观测被程序记为not_mentioned，只能证明模型没抽到该类型，不证明原文没有信息。因此该派生原因也不能直接用作“证据缺失”的监督真值。
- D的给定罪名与案情中的指控罪名不一致风险仍保留，未修改原始标签。正式CJOG数据处理须单独解决，不能由事实抽取结果掩盖。

## 对研究方向的判断

v1到v2的定位与结构稳定性改善，但规范、字段、句段表达都变了，不能将其归因于某个单独创新。当前**没有证据表明绑定在语义上优于平面抽取**，H3仍未成立。H1/H2未在真实CJOG模型上实验，核心egc对concat的问题仍待检验。

不进行第三轮针对这6例的提示修补，也不重复旧命令来追求通过率。按预设两轮预算，下一阶段缩小范围：暂从先导规则激活中移除全案未得逞条件，保留七项条件；该限制必须写入实验范围，不能声称覆盖完整量刑因素。结果条件只有在事件粒度和全案范围定义清楚后才考虑恢复。

进入冻结60例的新样本验证前，尚需完成一项工程准备：让unknown可以保留“解释为何不确定的上下文”，但与支持/反证证据严格区分；两组使用相同的规范和评估口径，新解析协议单独版本化，旧拒绝记录保持不变。这不是追加一轮规范调参，不能据新协议重写历史分数。该工程和七条件E3运行入口**本回合尚未实现，不提供未实现的命令**。

准备完成后才交由用户运行60例（诈骗/抢劫各30）的同案件对照，最多120次请求；新样本哈希保持冻结。先观察各条件的正/负/未知覆盖、漏抽和无依据判断，再决定选平面抽取还是绑定抽取。若绑定无增益，采用较简单方案，把资源转回真实规则及H2；不以“必须证明H3”作为继续条件。此时仍不启动全量训练或benchmark测试。
