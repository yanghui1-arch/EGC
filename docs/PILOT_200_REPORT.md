# 200条Flash试标与质量判断

本轮已完成200条真实API试标及批量完整性审计，并由Codex阅读固定随机样本30条和部分风险样本。结论：**保留Flash辅助标注路线，但不直接扩大当前“合成分析＋八情节联合生成”提示。** 需要先改善漏标、反证和主体/事件绑定。没有开始真实数据训练，也没有benchmark提升结果。

## 固定输入与实际结果

- 输入：`data/cail_pilot_v3/pilot200.jsonl`，全部来自原训练划分；不包含dev/test。
- 模型别名：`deepseek-flash`；关闭thinking；输出上限4096 tokens。
- 提示版本：`source-only-synthetic-analysis-v2`；标注规范：`fact-circumstances-v2`。本轮运行中没有更改这两个版本。
- 200次请求均收到完整JSON响应，197条通过结构与引文校验，3条被拦截：1条分析条数超过上限，2条引用在原文中多次出现。没有为这些结构失败自动重复付费。
- API报告输入193,384 tokens、输出149,029 tokens。按程序记录的2026-09-14峰值价格、全部输入按未命中计算，估计0.23685美元，仅为本轮估算，不是账单。
- 197条与原始输入、刑期、罪名和split逐项一致；全部条件及分析引用的字符跨度通过再次校验。原刑期标签没有发送给教师。

| 条件状态 | 数量 |
|---|---:|

| unknown | 1337 |
| 总数 | 1576 |

unknown约84.8%，不能直接解释为错误率。年龄条件197条全为unknown；前科只有1条supported，次要角色也只有1条supported。这说明当前均衡罪名样本对部分组合机制的覆盖很弱，不适合仅凭200条样本宣称规则组合有效。

## 审阅发现

审计程序标记46条，和固定种子42随机抽出的30条合并后，生成66条复核队列。启发式标记仅用于定位，不能作为错误计数。随机30条的案情、合成分析及八种状态已阅读；其他风险样本仅部分阅读。审阅者是模型，不是法律专家，未计算语义准确率。

1. **明确事实漏标。** 两条随机样本明写本案被告被抓获，主动到案仍为unknown；应依当前研究定义标为refuted。
2. **不充分的反证。** 一条仅因合谋和指认地点，就否定次要/辅助角色；这些事实本身不能排除该角色。
3. **合成文本引入细节。** 一条将匿名化原文中的山场写成“他人山场”，原文不足以支持该归属。部分摘要还省略“公诉机关指控”的来源。
4. **定义边界不一致。** 部分补栽是否属于已赔偿、庭审无异议是否等于如实供述、原地等候是否等于主动前往投案，需拆分客观行为后再组合。
5. **原始数据也有问题。** 有二审理由混在fact字段内，有原文金额算术不一致。后者不能归为教师幻觉，也不能擅自改原始刑期标签。

也观察到合理保留：警方追缴没有自动归成主动退赔；明确家属代退被识别；电话传唤后的主动性保留unknown。与首轮20条案件不同，本轮不能用这些例子声称修订提高了多少准确率。

逐案模型审阅记录位于本机 `data/flash_pilot200_v2/assistant_review.json`，原API响应、案情与标注不进入Git。

## 输入池修复

使用新增的 `input-outcome-and-appeal-v2` 筛查规则，从原1200条完整候选池中隔离36条：18条含上诉/原审说理，18条含原过滤器遗漏的量刑建议表达。新池为 `data/cail_screened_v5`，保留1047 train和117 dev，共1164条。

保留行的事实、标签、ID、划分完全不变，不重新抽样补足，不将dev变成train。原行完整保存在本机隔离文件中。此筛查是保守词面检查，不保证已经消除所有判决信息、同案改写或元数据错误。

本轮200条仍对应旧v3输入，不能把197条直接全用作新池训练数据。按新池ID求交后保留190条、排除7条；这190条仍是待语义修复的机器草稿，不等于已批准训练集。

## 下一步方法调整

将“事实条件抽取”和“分析文本生成”拆开。抽取阶段先固定主体、事件和时间，再提供支持/反证跨度；unknown需要区分未记载、归属不清和多个事件冲突。后续规则只消费有明确归属的事实。先用本轮发现的失败例做针对性回归，再使用独立新样本检查，避免只修好这几个例子。

优先保留原始刑期监督，合成分析作为可消融的教师产物。四组方法必须用相同的保留案件和训练目标，补充“有/无合成分析”的对照，避免把教师生成能力带来的变化归到EGC组合机制。增加规则覆盖样本时必须仅用train，并报告抽样改变；benchmark保持冻结。

代码检查：47项单元测试通过，四种变体的离线流程通过；这不等于GPU实验或benchmark测试。
