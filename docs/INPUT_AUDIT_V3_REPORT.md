## 复核覆盖与发现

本轮核对全部36条刑期标记的命中上下文，读完诈骗/抢劫范围内全部43条被标记案情，复核两对近重复全文，并回看E3的3条未命中范围疑点。对应76个不同记录的全部或指定风险；其余风险尚未完成语义裁决。助手复核不是独立人工金标准。

**量刑信息（高风险，文本证据明确）：** 36条中33条包含本案具体月数/年数的量刑建议或请求，不适合当前纯案情CJOG输入。其中包括多被告案件中的量刑请求，不能据此认定每条建议都对应源标签目标人物。另3条不属于这种数字泄漏：`21478f1614a0a4565bf0`是他人历史案件，`d9383613c18ef4a3bcaf`是前科，`f18faf685013fd46962d`是前刑/再犯时间表达。第三条另有目标罪名范围疑点，仍暂隔离；第一条的多罪标记也继续待审。不能因一个标记被排除，就把整行标成已通过。

**近重复（中风险，全文高度相符）：** 两对的关键时间、行为、金额、人物关系基本一致，差异主要为脱敏和名称写法。用于当前实验时按近重复处理，不能证明司法案号完全相同。

**原始标签/文本矛盾（高风险，溯源已确认）：** dev记录`20af0a63456bd7f9becc`的标签为抢劫，正文明确指控盗窃。回查官方压缩包`final_all_data/exercise_contest/data_train.json:9617`，原始accusation也为抢劫，relevant_articles为264，事实与本机完全一致；矛盾并非本机转换制造。不自动改成盗窃，不宣称知道最终正确刑期，先隔离。

**目标范围（高风险，具体标签归属仍不确定）：** 回查11个选定疑点的官方原记录，事实、给定罪名和刑期均与本机对应。多个原记录的meta只列一个罪名/人物，facts却含多罪或多人；当前`visible_case`只保留facts和charge，没有指定目标人物。单人物meta筛选不足以保证模型看到的任务唯一。12条范围疑点暂隔离；这些不是已经证实的12条错标签。若将来重新纳入，需要可追溯的目标人物/罪名映射及所有对照一致的输入协议，不能只给EGC补信息。

已溯源的11条ID后缀为：`a165af0927e807b6194a`、`5a5c195059e05229ff93`、`d6abff594582342f6b8a`、`54089cf5c182fc17e353`、`fdb28d88ef11606ef162`、`b4cf6f4784ca90e6cd3b`、`f18faf685013fd46962d`、`7a82670aba1ab9df84ca`、`806ec17cb237ea7ade6c`、`9d7195950182c0555721`、`20af0a63456bd7f9becc`。不据此推断未回查记录均正确。

**混合说理（高风险，如何分离仍待实现）：** 两罪名内另外25条包含法律定性、主从犯/累犯/未遂判断、处罚意见或法院采纳辩护等文本。事实与说理有时在同一句中，不能通用截断后自动视为干净输入。为当前机制先导暂整行隔离，保留未来基于跨度恢复的可能。这会改变样本组成，不是无成本的数据清洗，也不代表法律事实没有价值。
