## 局限与诊断

1. **主体绑定尚无增益证据。** H4预定bound相对flat至少3%改善门槛未达到；flat的信号只支持继续检查证据监督，不能算绑定创新成功。
2. 监督token/epoch分别732819、1632459、2050356。bound比flat多25.60%，仍未更优；flat对direct也有监督量混杂。不能把结果全归于结构。平均生成token约162.41/353.97/445.26，含失败输出。
3. 共同有效526案中，direct/flat/bound分别501/503/504案预测为12、36或120月（均超过95%）。实际train只有1807/4757（约38%）标签处于这三值，103种不同月份；dev为186/528，60种。存在明显输出集中现象，原因尚未确定，不归咎于未证实的标签改写。源标签与SFT目标hash已核对。
4. 定向阅读3个大误差变化案例及全部3份截断输出，不是盲审或全面语义评价。发现刑期更接近时摘要仍可能漏加金额；主体字段可能混合行贿人和受贿人。MAE改善不能替代说理准确性。原文引用命中flat为2062/2076、bound为2050/2064，仅说明逐字来源，不证明归属或因果正确。
5. 样本筛查误报/遗漏、剩余检方说理、教师主体噪声仍在；这不是原论文训练集和编码器复现，也不能与论文MAE直接比较。
